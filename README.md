## Overview

Disruption of the gut microbiota during cancer treatment — particularly in allogeneic hematopoietic cell transplantation (allo-HCT) — contributes to life-threatening bloodstream infections. This work introduces **pNODE**, a perturbation-aware Neural Ordinary Differential Equation framework that models microbial population dynamics in continuous time, integrating both microbial abundances and time-resolved antibiotic perturbations.

**Key contributions:**

- A neural ODE architecture that explicitly encodes antibiotic exposure as a time-dependent perturbation function, enabling the model to learn dynamics that depend on both microbial state and external treatment
- Systematic benchmarking against Generalized Lotka-Volterra (gLV) inference across >2,000 synthetic experiments varying noise, sampling density, and training set size — pNODE outperforms gLV under the sparse, noisy conditions characteristic of real clinical data, even when gLV generated the ground truth
- A pNODE trained on >10,000 microbiota samples from over 1,000 allo-HCT patients that achieves Pearson *r* = 0.63 on held-out 7-day predictions (vs. *r* = 0.172 for gLV on the same data)
- Prospective Bacilli abundance trajectories generated by the pre-trained pNODE outperform all ground-truth-based baselines for predicting *Enterococcus* bloodstream infections across multiple forecasting horizons

## Clinical Data Experiments

Located in `Clinical_Data_Experiments/`. The dataset consists of serial fecal microbiota profiles from allo-HCT patients at Memorial Sloan Kettering Cancer Center, including 16S rRNA sequencing, antibiotic treatment timelines, qPCR-based absolute abundances, and bloodstream infection outcomes (Liao et al. 2021).

**Preprocessing:** Microbiota samples are aggregated to 13 bacterial classes (12 named classes + a low-abundance group). Antibiotics are encoded as a 15-dimensional time-resolved binary vector (one entry per antibiotic category). The pNODE state dimension is *n* = 13 and the perturbation dimension is *k* = 15.

### Notebooks

| Notebook | Purpose |
|----------|---------|
| `train_node_model.ipynb` | Train the pNODE on clinical microbiome data using 7-day prediction windows |
| `train_glv_model.ipynb` | Train the gLV model (requires qPCR-based absolute abundances) |
| `predicting_dynamics_figures.ipynb` | Load pre-trained models and plot per-patient trajectory predictions |
| `predicting_bloodstream_infections_and_intestinal_dominations.ipynb` | Compute BSI risk scores and intestinal domination predictions; generates ROC curves and AUC values |
| `bacilli_abundance_prior_to_infection_plot.ipynb` | Plot Bacilli abundance timelines leading up to *Enterococcus* infections |

### Model file

`models_and_functions.py` contains:
- `PureNeuralODE` — pNODE architecture with 15-antibiotic perturbation encoding fed into a 3-layer feedforward net (tanh activations)
- `GLVmodel` — gLV with ridge regression fitting and the same perturbation interface
- Training utilities: batching, MAE loss with variable-length sequence padding, R² evaluation

## In Silico Experiments

Located in `In_Silico_Experiments/`. A 5-species synthetic ecosystem governed by a perturbation-augmented gLV is used as a controlled benchmark with known ground truth.

### Files

| File | Purpose |
|------|---------|
| `generate_ground_truth_coefficients.py` | Sample gLV interaction matrix, growth rates, and perturbation coefficients from a multivariate normal; saves as `.npy` files |
| `run_experiment.py` | Load ground-truth coefficients, generate synthetic data (Latin hypercube initial conditions, Gaussian noise, random perturbation windows), then train and evaluate both pNODE and gLV, saving test R² results |
| `models.py` | pNODE and gLV model implementations for the synthetic setting |
| `make_args.py` | Generate `args.txt` with all combinations of noise, sampling density, and training size for batch runs |
| `job_array.sh` | SLURM job array script that runs up to 2,268 independent experiments in parallel |
| `train_node_to_make_predicted_vs_true_plots.py` | Train and save pNODE instances at different test loss values for qualitative trajectory comparisons |

### Running a single experiment

```bash
python run_experiment.py --noise 0.1 --density 10 --training_size 50
```

Key arguments:

| Argument | Description | Default |
|----------|-------------|---------|
| `--noise` | Gaussian noise level (fraction) | required |
| `--density` | Number of subsampled time points per trajectory (out of 48) | required |
| `--training_size` | Number of training trajectories | required |
| `--training_time` | Wall-clock training time in seconds | 100 |
| `--node_test_rsquared_goal` | Early-stopping R² threshold | 0.98 |
| `--replicate` | Replicate index (for distinguishing output files) | 1 |

Results are saved to `data/experimental_results/` as `.npy` files.

### Running the full experiment grid (HPC)

```bash
# 1. Generate ground-truth coefficients
python generate_ground_truth_coefficients.py

# 2. Generate args.txt with all parameter combinations
python make_args.py

# 3. Submit job array (edit resource requests in job_array.sh as needed)
sbatch job_array.sh
```
